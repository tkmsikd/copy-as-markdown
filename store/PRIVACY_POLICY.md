# Privacy Policy — Copy as Markdown

**Last updated:** February 20, 2026

## Overview

Copy as Markdown is a browser extension that converts web page content to Markdown format. Your privacy is important to us.

## Data Collection

**We do not collect, store, or transmit any data.** Specifically:

- ❌ No personal information collected
- ❌ No browsing history tracked
- ❌ No analytics or telemetry
- ❌ No cookies used
- ❌ No external API calls
- ❌ No data sent to any server

## How It Works

All processing occurs **entirely within your browser**:

1. When you use the context menu or popup button, the extension reads the current page's DOM content
2. The HTML is converted to Markdown locally using JavaScript
3. The resulting Markdown is copied to your system clipboard
4. No data leaves your browser at any point

## Permissions Used

| Permission       | Purpose                                                  |
| ---------------- | -------------------------------------------------------- |
| `contextMenus`   | Add right-click menu options                             |
| `activeTab`      | Access the current tab's content when you click the menu |
| `clipboardWrite` | Copy the converted Markdown to your clipboard            |

## Third-Party Services

This extension does **not** use any third-party services, APIs, or libraries that collect data.

## Changes to This Policy

If we make changes to this privacy policy, we will update the "Last updated" date above.
