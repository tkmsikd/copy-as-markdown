# Chrome Web Store — Listing Assets

## Short Description (132 chars max)

Copy selected text, links, images, or entire pages as clean Markdown with one right-click. Supports tables, code blocks & nested lists.

## Detailed Description

📋 **Copy as Markdown** — The fastest way to copy web content as Markdown.

**One right-click is all it takes.**

Stop manually converting web pages to Markdown. Copy as Markdown instantly transforms:

🔹 **Selected text** → Clean, formatted Markdown
🔹 **Links** → `[text](url)` format
🔹 **Images** → `![alt](src)` format
🔹 **Full pages** → Complete Markdown document with source link

### ✨ Comprehensive HTML Support

Unlike other Markdown copy tools, Copy as Markdown handles **everything**:

- ✅ Headings (h1–h6)
- ✅ Bold, italic, strikethrough, inline code
- ✅ Tables → Markdown tables
- ✅ Code blocks with language detection
- ✅ Nested lists (ordered & unordered)
- ✅ Blockquotes
- ✅ Images with alt text
- ✅ Links

### 🎯 How to Use

1. **Select text** on any page → Right-click → "Copy Selection as Markdown"
2. **Right-click a link** → "Copy Link as Markdown"
3. **Right-click an image** → "Copy Image as Markdown"
4. **Right-click on the page** → "Copy Page as Markdown"
5. Or click the extension icon for quick page/selection copy

### 🔒 Privacy

- No data collection

- No tracking
- All processing happens locally in your browser

Perfect for developers, writers, and anyone who works with Markdown!
