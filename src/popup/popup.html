📋 Copy as Markdown

Right-click on any page to copy content as Markdown.

Context Menu

  • Copy Selection — Selected text → Markdown
  • Copy Link — Link → [text](url)
  • Copy Page — Full page → Markdown
  • Copy Image — Image → ![](url)

Keyboard Shortcuts

  • ⌘ + ⇧ + C — Copy Selection
  • ⌘ + ⇧ + M — Copy Page
